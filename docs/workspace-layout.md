# Workspace Layout

- `src/`: React UI, deterministic game rules, and local persistence adapter.
- `docs/`: product, architecture, design, testing, and memory documentation.
- `.gemini/`: compact operational memory and dated session logs.
- `public/`: static browser assets.
- `dist/`: ignored build output.

This is a single Vite application. No empty service, API, or infrastructure directories are required.
